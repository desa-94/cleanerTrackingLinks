# Auto Tracker Link Generator 📦

A compact Python tool for everyday use, designed to quickly generate tracking links and pre-formatted email notifications.

## Features

* **Automatic detection:** Identifies parcel carriers (e.g. UPS, DHL) based on the tracking number.
* **QWERTY/QWERTZ correction:** Automatically corrects common typing errors (e.g. mistyping `1Y` as `1Z` in UPS tracking numbers).
* **Clipboard integration:** Copies the finished tracking link directly to the clipboard...
